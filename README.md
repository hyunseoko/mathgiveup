# 📘 SMath
게이미피케이션 기반 수학 학습 앱 – **수포자 방지 프로젝트**


## 📌 프로젝트 소개
게이미피케이션 요소를 활용하여 학생들의 학업 스트레스를 줄이고, 수학에 대한 흥미를 높여 학습 격차를 완화하는 것을 목표로 한 수학 학습 앱


## 📝 개발 배경 및 필요성
- 한국 학생들은 수학에서 높은 성취도를 보이지만, 학교 내 성취도 격차가 큼  
- 학습자의 실력에 맞춘 문제를 제공하는 새로운 시스템이 필요
- 이를 통해 학습자의 수준에 맞춘 맞춤형 수학 학습 환경을 제공


## 🌟 프로젝트 특·장점
- **커뮤니티 기능**: 사용자 간 상호작용을 촉진하고 학교 대항전으로 학습의 재미를 높임  
- **지속적인 학습 유도**: 학습 동기부여 및 꾸준한 학습 환경 제공  
- **게임 요소**: 성취감을 통한 몰입도 향상  


## ⚙️ 주요 기능
- **실력 테스트**: 수학 문제를 자동 생성하고 성취도 확인  
- **게임화 알고리즘**: 좌표 변환, 랜덤 위치 생성 알고리즘  
- **문제 계산 API**: Wolfram Alpha API 활용  
- **커뮤니티 경쟁**: 학교/그룹 단위 대항전  


## 🚀 기대효과 및 활용 분야
- 학습 격차 해소 및 창의적 사고 증진  
- 중학생을 시작으로 다양한 교육 단계로 확장 가능  
- 보충학습 도구, 개인 맞춤형 학습 지원, 시험 준비 도구 등으로 활용
